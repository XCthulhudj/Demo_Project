一、文件操作

主要内容：如何通过 Python 读取、创建、修改和保存文件。

1. 打开文件

使用 open()：

file = open("test.txt", "r", encoding="utf-8")

常见打开模式：

模式含义
r只读，文件不存在会报错
w只写，文件不存在则创建，存在则清空
a追加写入，文件不存在则创建
x创建新文件，文件已存在则报错
b二进制模式
+同时支持读取和写入

例如 rb 表示以二进制模式读取文件；w+、a+ 也常出现在日志与缓存代码里。

2. 读取文件

file = open("test.txt", "r", encoding="utf-8")
data = file.read()
print(data)
file.close()

常用读取方法：

file.read()        # 读取全部内容，返回一个字符串
file.readline()    # 读取一行
file.readlines()   # 读取所有行，返回列表

注意：上例用的是 file 这个变量名；写成 open(...) 直接调用也一样，但没法再操作同一个文件对象。

3. 写入文件

file = open("test.txt", "w", encoding="utf-8")
file.write("Hello Python\n")
file.write("Hello World")
file.close()
  • write()：写入字符串（写数字要先 str()）。
  • w：会覆盖原有文件内容。
  • a：在文件末尾追加内容。
别拿 w 写日志 w 打开的一瞬间原文件就已经被清空了 —— 哪怕你一行都没写。循环里反复用 w 打开同一个文件，最终只会剩下最后一次的内容，追加请用 a。

4. 使用 with 管理文件（重点）

这是非常重要的知识点，建议重点掌握。

with open("test.txt", "r", encoding="utf-8") as file:
    data = file.read()
    print(data)

使用 with 后，代码块执行结束会自动关闭文件，不需要手动调用 close()。

为什么一定要用 with 手动 close() 的写法，一旦中途抛异常（比如解码失败），close() 就被跳过了，文件句柄会泄漏、Windows 上还会锁住文件删不掉。 with 保证任何情况下都会关文件，等价于 try ... finally: file.close()。

5. 文件路径

需要了解相对路径和绝对路径：

# 相对路径：相对于"运行脚本时的当前目录"
open("data/test.txt", "r")

# 绝对路径：从盘符开始，注意 Windows 的反斜杠要用 r"" 转义
open(r"D:\Data\test.txt", "r")

还可以学习 pathlib 模块，用对象的方式拼路径、判断文件是否存在：

from pathlib import Path

p = Path("data") / "test.txt"      # 用 / 拼接，跨平台不用管分隔符
print(p.exists())                  # 文件是否存在

p.parent.mkdir(parents=True, exist_ok=True)   # 目录不存在就建
p.write_text("hello", encoding="utf-8")       # 直接读写文本，内部已经 with

6. 进阶：JSON 文件操作

JSON 常用于保存配置参数、设备信息和通信数据。推荐格式：ensure_ascii=False 让中文正常显示，indent=4 让文件可读。

import json

data = {
    "name": "Robot",
    "speed": 100
}

# 写入 JSON
with open("config.json", "w", encoding="utf-8") as file:
    json.dump(data, file, ensure_ascii=False, indent=4)

# 读取 JSON
with open("config.json", "r", encoding="utf-8") as file:
    result = json.load(file)

print(result["name"])

二、异常处理

异常就是程序运行过程中出现的错误或异常情况。例如：

num = 10 / 0

会产生 ZeroDivisionError，导致程序中断：

Traceback (most recent call last):
  File "demo.py", line 1, in <module>
    num = 10 / 0
ZeroDivisionError: division by zero

1. try 和 except

这是异常处理最基础的结构：

try:
    num = 10 / 0
except ZeroDivisionError:
    print("不能除以零")

执行逻辑：

  • try：尝试执行可能出错的代码。
  • except：发生指定异常时执行对应代码；没发生就跳过。

2. 常见异常类型

异常常见原因
NameError使用未定义的变量
TypeError数据类型使用错误
ValueError值不符合要求
IndexError列表索引越界
KeyError字典键不存在
FileNotFoundError文件不存在
ZeroDivisionError除数为零
ImportError导入模块失败

这些常见异常建议认识并掌握 —— 看到报错信息的第一行，能立刻知道大概是什么问题。

3. 多个 except

不同类型的异常可以分别处理：

try:
    num = int(input("请输入数字："))
    result = 100 / num
except ValueError:
    print("输入的不是整数")
except ZeroDivisionError:
    print("不能输入零")

4. else 和 finally

完整的异常处理结构：

try:
    num = 10 / 2
except ZeroDivisionError:
    print("发生异常")
else:
    print("程序正常执行")
finally:
    print("无论是否发生异常，都会执行")
  • else：没有发生异常时执行。
  • finally：无论是否发生异常，通常都会执行，常用于资源清理（关文件、关串口、释放连接）。

5. raise 主动抛出异常

可以自己判断条件，并主动抛出异常：

def set_speed(speed):
    if speed < 0:
        raise ValueError("速度不能为负数")
    print("设置速度成功")

set_speed(-10)

raise 可以主动触发异常，避免非法参数进入后续程序 —— 在机械臂上位机里，速度、角度、限位这类参数建议都在入口处校验。
