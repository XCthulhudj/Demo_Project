PYTHON 面向对象 · 第 2 讲

继承 与 封装

用「电机」的例子讲清楚两个核心特性，并落到机械臂项目的类设计上

继承（Inheritance）和封装（Encapsulation）是面向对象编程的两个重要特性：继承解决"代码复用"，封装解决"数据访问"。

1　继承（Inheritance）

继承就是一个类可以继承另一个类的属性和方法，从而减少重复代码。先定义一个父类 Motor，再定义两个不同的电机子类：

# 父类
class Motor:
    def __init__(self, motor_id):
        self.motor_id = motor_id

    def start(self):
        print("电机启动")


# 子类
class ServoMotor(Motor):
    def rotate(self):
        print("舵机旋转")


class StepMotor(Motor):
    def step(self):
        print("步进电机转动")

使用：

servo = ServoMotor(1)
servo.start()      # 继承父类的方法
servo.rotate()     # 调用自己的方法
print(servo.motor_id)

输出：

电机启动
舵机旋转
1

这里需要理解：

  • Motor：父类（基类）。
  • ServoMotor、StepMotor：子类（派生类）。
  • class ServoMotor(Motor)：表示 ServoMotor 继承 Motor。
  • 子类可以直接使用父类的属性和方法（上例中 start() 和 motor_id 都来自父类）。

方法重写（Override）

子类还可以重新定义父类的方法：

class Motor:
    def start(self):
        print("普通电机启动")


class ServoMotor(Motor):
    def start(self):
        print("舵机启动")

调用：

servo = ServoMotor()
servo.start()

输出：

舵机启动

如果想在子类中调用父类的方法，可以使用 super()：

class ServoMotor(Motor):
    def start(self):
        super().start()          # 先执行父类的 start()
        print("舵机进入工作状态")
为什么用 super() 而不是 Motor.start(self) 写 super().start() 时，父类改了名字或换了层级，子类不需要跟着改；多继承时它也会按 MRO 正确找到下一个类。

2　封装（Encapsulation）

封装就是将数据和操作数据的方法放在一个类中，同时限制外部直接访问某些内部数据。Python 中常见三种属性命名方式：

写法含义
name公有属性，可以直接访问
_name受保护约定，建议只在内部使用（外部仍能访问，只是"别这么干"）
__name名称改写（name mangling），限制直接访问

例如：

class Motor:
    def __init__(self):
        self.name = "DM-J4310"        # 公有
        self._speed = 100             # 受保护
        self.__temperature = 30       # 私有（名称改写）

    def get_temperature(self):
        return self.__temperature

使用：

motor = Motor()
print(motor.name)                # 正常
print(motor._speed)              # 可以访问，但约定上不建议
print(motor.get_temperature())   # 通过方法获取温度

__temperature 不适合直接通过 motor.__temperature 访问。

名称改写的真相 双下划线并不是"真正禁止访问"，Python 会把它改写成 _Motor__temperature，所以 motor._Motor__temperature 依然读得到。它的作用是挡住误用，而不是安全防护。

这里的设计思想是：外部不直接操作内部数据，而是通过类提供的方法来访问和修改数据。这样以后想在赋值时加校验（比如转速必须为正），只改方法，不用改所有调用处。

3　两者有什么区别？

特性继承封装
核心目的代码复用隐藏内部实现、管理数据访问
主要方式父类与子类属性与方法
关键语法class A(B)self.__xxx
典型应用不同类型电机共用基础功能限制电机参数的访问和修改

4　结合机械臂项目理解

可以设计这样的类结构：

Motor电机基类 · 启动 / 停止 / 设置速度
ServoMotor舵机控制
JointMotor关节电机控制

通过继承复用基础功能，子类实现各自的控制逻辑：Motor 里放 start()、stop()、set_speed() 和封装好的状态字段；ServoMotor、JointMotor 只写自己特有的部分（如角度回零、限位检查）。

记忆
  • 继承：子类继承父类的属性和方法（class 子类(父类)）。
  • 封装：将数据和操作数据的方法组织在一起，并控制访问方式（self.__xxx）。

这两个概念掌握后，可以继续学习 Python 面向对象的第三个重要特性：多态（Polymorphism）。
